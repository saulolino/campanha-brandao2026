## Ideia 1: "Command Center Militar Verde"

**Design Movement:** Military Dashboard / War Room adaptado com paleta orgânica
**Core Principles:**
1. Informação densa e hierarquizada com prioridade visual clara
2. Tipografia monospace para dados, serif para títulos — contraste funcional
3. Fundo escuro com acentos em verde-floresta e dourado — evoca autoridade e natureza
4. Painéis modulares com bordas finas que lembram telas de monitoramento

**Color Philosophy:** Fundo grafite escuro (#1a1f2e) com verde-floresta (#2d6a4f) como cor primária, dourado suave (#c9a84c) para destaques e alertas, branco-gelo para texto principal. A paleta transmite seriedade, controle e conexão com a natureza.

**Layout Paradigm:** Grid assimétrico com sidebar fixa à esquerda (navegação vertical), área principal dividida em cards de tamanhos variados, header fino com métricas em tempo real. Inspirado em dashboards de controle de missão.

**Signature Elements:**
1. Indicadores circulares animados (gauges) para métricas de crescimento
2. Linha do tempo vertical com marcos da campanha
3. Cards com borda lateral colorida indicando status (verde=ok, amarelo=atenção, vermelho=crítico)

**Interaction Philosophy:** Hover revela detalhes adicionais em tooltip escuro. Transições suaves de 200ms. Clique em cards expande para detalhes.

**Animation:** Números contam de 0 até o valor real ao entrar na viewport. Barras de progresso preenchem suavemente. Cards entram com fade-in escalonado.

**Typography System:** DM Sans para títulos (bold, tracking tight), JetBrains Mono para números/dados, DM Sans regular para corpo de texto.

## Ideia 2: "Botanical Dashboard"

**Design Movement:** Organic Modernism — interfaces que respiram natureza com precisão suíça
**Core Principles:**
1. Fundo claro com textura sutil de papel reciclado
2. Formas orgânicas suaves (border-radius generosos, ondulações)
3. Ilustrações botânicas como elementos decorativos
4. Dados apresentados com clareza absoluta em cards com sombras suaves

**Color Philosophy:** Branco quente (#faf8f5) como base, verde-sage (#5a7d5a) como primária, terracota (#c4704b) para alertas, azul-petróleo (#2c5f6e) para dados secundários. A paleta evoca sustentabilidade, calma e confiança.

**Layout Paradigm:** Layout de revista editorial — seções com larguras variadas, uso de whitespace generoso, cards flutuantes com sombras longas. Navegação por tabs horizontais no topo. Sem sidebar — conteúdo flui verticalmente.

**Signature Elements:**
1. Ícones desenhados à mão (estilo botanical illustration) para cada seção
2. Divisores ondulados entre seções (SVG waves em verde-sage)
3. Gráficos com gradientes suaves e cantos arredondados

**Interaction Philosophy:** Scroll suave entre seções. Cards elevam-se sutilmente no hover. Transições orgânicas com easing curves naturais.

**Animation:** Elementos aparecem com slide-up suave ao scrollar. Gráficos desenham-se progressivamente. Números incrementam organicamente.

**Typography System:** Playfair Display para títulos (elegante, editorial), Source Sans 3 para corpo e dados. Contraste forte entre display e texto.

## Ideia 3: "Brasília Brutalist Data"

**Design Movement:** Neo-Brutalism Digital — inspirado na arquitetura de Brasília (Niemeyer/Costa) com dados em primeiro plano
**Core Principles:**
1. Geometria forte — linhas retas, ângulos de 45°, formas monumentais
2. Tipografia grande e impactante como elemento visual principal
3. Cores sólidas em blocos — sem gradientes, sem sombras suaves
4. Dados são a decoração — números gigantes, gráficos dominantes

**Color Philosophy:** Branco puro (#ffffff) como base, concreto (#e8e4df) para cards, verde-cerrado (#1b4332) como primária forte, laranja-ipê (#e76f51) para CTAs e alertas, preto (#1a1a1a) para texto. Inspirado no concreto de Brasília + cores do cerrado.

**Layout Paradigm:** Grid brutalista com blocos de tamanhos contrastantes — um card gigante ao lado de três pequenos. Bordas grossas (3-4px) em preto. Sem border-radius. Assimetria proposital. Sidebar com blocos empilhados.

**Signature Elements:**
1. Números de métricas em tamanho display (80-120px) como elemento visual dominante
2. Bordas grossas pretas com offset shadows (estilo neo-brutalist)
3. Barras de progresso retangulares sólidas sem arredondamento

**Interaction Philosophy:** Hover causa deslocamento do shadow (2px shift). Cliques têm feedback tátil com scale(0.98). Sem transições suaves — mudanças são instantâneas e decisivas.

**Animation:** Mínima — apenas contagem de números. A brutalidade está na estaticidade. Scroll snap entre seções.

**Typography System:** Space Grotesk para tudo — bold para títulos (tracking -0.02em), medium para dados, regular para corpo. Uma única família, múltiplos pesos.
</text>

## Decisão: Ideia 1 — "Command Center Militar Verde"

Escolho a Ideia 1 por ser a mais adequada para uma plataforma interna de equipe de campanha. O conceito de "Command Center" transmite seriedade, controle e foco em resultados — exatamente o que uma equipe de campanha precisa. A paleta escura com verde-floresta conecta diretamente com "Brasília Cidade Parque" e o fundo escuro reduz fadiga visual para uso prolongado.
